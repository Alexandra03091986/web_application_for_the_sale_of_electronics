## 🎯О проекте
Приложение представляет собой CRM-систему для управления сетью по продаже электроники с трехуровневой иерархией:

- **Завод** (уровень 0)
- **Розничная сеть** (уровень 1)  
- **Индивидуальный предприниматель** (уровень 2)

### Основные возможности:
- Управление поставщиками, контактами и продуктами
- Иерархическая структура с возможностью ссылаться на любого поставщика
- Учет задолженности между звеньями сети
- API с полным CRUD и фильтрацией
- Документация Swagger/ReDoc
- Админ-панель с кастомными действиями

## 📊Модель данных

### Contact (Контакты)
- `email` - Email
- `country` - Страна
- `city` - Город
- `street` - Улица
- `house_number` - Номер дома

### Product (Продукты)
- `name` - Название
- `model` - Модель
- `release_date` - Дата выхода на рынок

### Supplier (Поставщик)
- `name` - Название
- `level` - Уровень сети (0, 1, 2)
- `contact` - Связь с контактами (OneToOne)
- `products` - Связь с продуктами (ManyToMany)
- `supplier` - Поставщик (ForeignKey на себя)
- `debt` - Задолженность перед поставщиком
- `created_at` - Время создания

## 🚀Установка и запуск

### Предварительные требования
- Python 3.13+
- PostgreSQL 10+
- Poetry

### Пошаговая инструкция

1. **Клонировать репозиторий**
```
git clone https://github.com/Alexandra03091986/web_application_for_the_sale_of_electronics/tree/feature/creating_project
cd web-application-for-the-sale-of-electronics
```

2. Установить зависимости через Poetry
```
poetry install
```

3. Активировать виртуальное окружение
```
poetry shell
```

4. Создать базу данных PostgreSQL
```
CREATE DATABASE electronics_db;
```

5. Настроить переменные окружения
Создайте файл .env в корне проекта:

```
SECRET_KEY=your-secret-key-here
DEBUG=True

POSTGRES_DB=electronics_db
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```

6. Применить миграции
```
python manage.py makemigrations
python manage.py migrate
```

7. Создать суперпользователя
```
python manage.py createsuperuser
```
8. Загрузить тестовые данные (фикстуры)
```
python manage.py loaddata initial_data
```
9. Запустить сервер
```
python manage.py runserver
```

# 📚API Документация
После запуска сервера документация доступна по адресам:

- Swagger UI: http://127.0.0.1:8000/swagger/
- ReDoc: http://127.0.0.1:8000/redoc/


### Основные эндпоинты
| Метод	  | URL	                                              | Описание                        |
|:--------|:--------------------------------------------------|:--------------------------------|
| GET    | `/api/suppliers/`                                 | Список поставщиков | 
|POST	| ` /api/suppliers/`	                               | Создать поставщика  |
|GET	| `/api/suppliers/{id}/`	                           | Детали поставщика       |
|PATCH	| `/api/suppliers/{id}/`	                           | Частичное обновление     |
|PUT	| `/api/suppliers/{id}/`	                                               | Обновить поставщика       |
|DELETE	| `/api/suppliers/{id}/`	                           | Удалить поставщика       |


### Фильтрация и поиск
- **Фильтрация по стране:** ``/api/suppliers/?contact__country=Россия``
- **Фильтрация по уровню:** ``/api/suppliers/?level=1``
- **Поиск по названию:** ``/api/suppliers/?search=завод``
- **Поиск по городу:** ``/api/suppliers/?search=Москва``
- **Сортировка:** ``/api/suppliers/?ordering=-debt``

### Права доступа
- API доступно только для активных сотрудников (`is_active=True` и `is_staff=True`)

- Поле `debt` доступно только для чтения через API (нельзя обновить через POST/PUT/PATCH)

## 🔧 Админ-панель
Админ-панель доступна по адресу: http://127.0.0.1:8000/admin/

### Возможности админ-панели:
1. **Управление поставщиками**
   - Просмотр списка с ссылками на поставщиков
   - Фильтрация по городу и стране
   - Поиск по названию

2. **Admin actions**
   - Очистка задолженности у выбранных поставщиков

3. **Управление контактами и продуктами**
   - Полный CRUD для контактов
   - Полный CRUD для продуктов
